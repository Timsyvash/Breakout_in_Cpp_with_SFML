# Breakout (SFML Game)

Класична аркадна гра **Breakout**, реалізована мовою C++ з використанням графічної бібліотеки **SFML 2.x**.

---

## 🎮 Ігровий процес та управління

Мета гри — знищити всі кольорові блоки на екрані, відбиваючи м'яч за допомогою ракетки. Якщо м'яч падає нижче ракетки — гра закінчується.

* **`A` / `Left Arrow`** — Рух ракетки ліворуч
* **`D` / `Right Arrow`** — Рух ракетки праворуч
* **`P`** — Пауза / Відновити гру
* **`R`** — Перезапуск гри (після `Game Over` або `Win`)

---

## 🛠 Особливості реалізації

* **Архітектура:** Розділення логіки гри на класи (`Ball`, `Paket`, `BlockManager`, `Game`) із використанням концепції `GameContext` та розумних вказівників (`std::shared_ptr`, `std::unique_ptr`).
* **Динамічна генерація:** Автоматичне створення сітки блоків із випадковими яскравими кольорами (RGB).
* **Фізика та колізії:** Обробка AABB-колізій для відскоку м'яча від стінок, ракетки та руйнування блоків.
* **Кадрово-незалежна фізика:** Використання `Delta Time` для стабільної швидкості об'єктів незалежно від FPS екрана.
